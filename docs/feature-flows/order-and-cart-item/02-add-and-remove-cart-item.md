## Flow
(Setup: login + go to a course page)
1. locate the button showing either 
   - course adding, 
   - course removing, or 
   - not-available
2. if purchased
   - button being disabled and shows already-purchased
3. if not purchased & not in the cart
   - button shows add-to-cart => click to see a success message
4. go to cart-inventory => see the course is actually added
5. go back to the course page
6. if not purchased, but in the cart
   - button shows remove-from-cart => click to see a success message
7. go to cart-inventory => see the course is actually removed
